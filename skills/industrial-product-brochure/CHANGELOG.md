# Changelog

## 1.0.0 - Reusable open-source baseline

- Added a stricter page workflow with buyer-view design, art direction, compact design brief, editor review, and print delivery.
- Added `references/design-review.md` for self-rejection, revision layer diagnosis, and local repair rules.
- Added reusable templates for page manifests and print-shop instructions.
- Expanded project lessons with design-before-prompting, editor self-rejection, and final-stage repair guidance.
- Expanded image-generation notes to separate design brief, exact text, locked assets, and generated visuals.
- Expanded print-prepress notes for stale PDFs and background-aware final-stage repair.
- Expanded eval prompts to cover visible repair patches, prompt overload, and machine-scale failures.
- Removed local/project-specific identity from the license so the package is easier to publish.
