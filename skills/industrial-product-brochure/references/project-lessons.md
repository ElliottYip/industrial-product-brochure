# Project Lessons

These lessons were distilled from a real 24-page industrial machinery brochure project. They are intentionally generic so the skill can transfer to other equipment categories.

## 1. Product Comes First

A product brochure is not a poster, a landing page, or a design exercise. If the product is a machine, the machine must be visible enough for a buyer to inspect. Samples, process graphics, and slogans are support evidence.

## 2. Asset Truth Beats Prompt Creativity

When several machines look similar, free image generation can swap models or invent structures. Lock the asset set, map each file to a model/application, and use deterministic layout when identity matters.

## 3. White Canvas Is Not Product Area

Many machinery photos sit on large white backgrounds. Measuring the image box makes the machine look larger than it prints. Measure the visible machine body.

## 4. Buyer Logic Should Shape Layout, Not Copy

Customers should understand the page by scanning products, machines, ranges, and samples. Do not print internal guide copy such as "look here first" unless the page is explicitly a selection guide.

## 5. Good-Looking Can Still Fail

A page can be balanced and still not sell. Run the sales gate: recognition, model match, range boundary, trust proof, and inquiry hook.

## 6. Feedback Needs Diagnosis

When a draft is rejected, classify the failure:

- truth failure;
- scale failure;
- material/sample failure;
- communication failure;
- copy-tone failure;
- genre failure;
- role failure.

Fix the failing layer instead of overcorrecting the entire page.

## 7. Bilingual Catalogs Need Chinese-First Scanning

For mixed domestic and overseas audiences, Chinese-first paired labels often scan better than separate bilingual paragraphs. Use deliberate CJK fonts.

## 8. Covers and Back Covers Have Their Own Grammar

Do not reuse product-page corner marks, page tabs, machine cards, or model blocks on a back cover. A back cover can be quiet: logo, company, scope, contact, and enough white space.

## 9. References Are Critique Inputs, Not Approval

Design references, Open Design outputs, or famous-company brochures can sharpen taste. They do not excuse weak role fit, clutter, or generic composition.

## 10. Print Delivery Is Part of the Job

The project is not finished when the last page image is approved. Final delivery should include page-order verification, A4 PDF, original-image ZIP, print instructions, bleed note, and proofing advice.

## 11. Design Before Prompting

When a page is generated directly from a long rule dump, the model may satisfy fragments while missing the brochure role. First describe the page as a designed object: role, reader first glance, visual mass, grid, evidence, tone, and prohibitions. Then compress that into a short prompt or deterministic layout plan.

## 12. Self-Rejection Saves Iterations

The agent should act like a strict editor before the user sees a draft. If the page looks like a website, manual, poster, or generic template, reject it internally and rebuild the failing layer.

## 13. Repair Work Must Respect the Existing Surface

Final-stage changes such as page numbers, logos, or footers should not leave visible patches. If a page background is not pure white, do not cover old marks with a white rectangle. Reconstruct the local background and verify in a contact sheet.
